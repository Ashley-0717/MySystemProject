# 微头条 · 控制台单机版 业务流程图

> 依据真实代码绘制（`src/App.jsx`、`src/store.js`）。

## 1. 应用启动与整体导航

```mermaid
flowchart TD
    A[启动 bun src/index.js] --> B[render &lt;App/&gt; 挂载 Ink]
    B --> C{db.json 存在且可解析?}
    C -- 否 --> D[load 使用 seed 种子数据]
    C -- 是 --> E[load 读入内存 db]
    D --> F[view = login 登录视图]
    E --> F
    F --> G{登录 / Tab 切注册}
    G -- 注册成功 --> F
    G -- 登录成功 --> H[view = main 首页]
    H --> I{快捷键路由}
    I -- n --> P[发布视图 publish]
    I -- Enter 选中 --> DT[详情视图 detail]
    I -- m --> M[我的头条 mine]
    I -- p --> PF[个人中心 profile]
    I -- o --> N[公告 notices]
    I -- a 且 role=1 --> AD[管理面板 admin]
    I -- q --> Z[exit 退出程序]
```

## 2. 登录 / 注册时序

```mermaid
sequenceDiagram
    participant U as 用户(终端按键)
    participant L as LoginView(App.jsx:74)
    participant S as store.js
    participant F as db.json

    U->>L: 输入用户名/密码(Tab 逐项)
    U->>L: Enter 提交
    alt 登录视图
        L->>S: store.login({username,password})
        S->>S: db.users.find 匹配用户名+密码
        alt 匹配失败
            S-->>L: null → 显示"用户名或密码错误"
        else 匹配成功
            S-->>L: 用户对象
            L-->>U: 进入 main,显示"欢迎,{昵称}"
        end
    else 注册视图
        L->>S: store.register({username,password,confirm,nickname})
        S->>S: 非空/一致/长度/重名校验
        alt 校验失败
            S-->>L: 错误文案 → 显示
        else 校验通过
            S->>F: users.push + save() 原子落盘
            S-->>L: null → "注册成功,请登录"切回登录
        end
    end
```

## 3. 发布 / 编辑头条流程

```mermaid
flowchart TD
    A[首页按 n → publish 视图] --> B[填写标题 Tab 切换 填写内容 ←→ 选类型]
    B --> C{按 1 发布 / 编辑时按 1 保存}
    C -- 取消/Esc --> Z[返回 main / mine]
    C --> D{edit?}
    D -- 是 --> E[store.update hid,uid,role,数据]
    D -- 否 --> F[store.publish uid,数据]
    F --> F1{标题非空? 内容非空?≤5000字? 类型有效?}
    F1 -- 否 --> ERR[显示错误信息]
    F1 -- 是 --> F2[headlines.push 初始计数全 0]
    F2 --> S1[save 落盘 → "发布成功" 回首页]
    E --> E1{头条存在? 本人或管理员? 标题内容非空?}
    E1 -- 否 --> ERR2[显示错误信息]
    E1 -- 是 --> E2[更新 title/content/update_time 管理员可改 typeId]
    E2 --> S2[save 落盘 → "修改成功" 回我的]
```

## 4. 浏览详情 + 点赞 + 评论时序

```mermaid
sequenceDiagram
    participant U as 用户
    participant M as MainView/DetailView
    participant S as store.js
    participant F as db.json

    U->>M: 首页 ↑↓ 选中条目,Enter
    M->>S: store.detail(id)
    S->>S: h.view_count++
    S->>F: save() 落盘(浏览量统计)
    S-->>M: 头条对象 + commentsOf(hid) 评论列表
    M-->>U: 渲染详情/评论/点赞状态

    alt 点赞(按 l)
        M->>S: store.toggleLike(hid, uid)
        S->>S: likes 中查找 (hid,uid) 记录
        alt 已点赞
            S->>S: 删除记录, like_count-1
            S-->>M: {liked:false} "已取消点赞"
        else 未点赞
            S->>S: likes.push, like_count+1
            S-->>M: {liked:true} "点赞成功"
        end
        S->>F: save() 落盘
    end

    alt 发表评论(按 i 或 / 输入,r 回复选中)
        M->>S: store.addComment(hid, uid, content, replyTo)
        S->>S: 非空/≤500字校验
        S->>S: comments.push(parent_cid=replyTo), comment_count++
        S->>F: save() 落盘
        S-->>M: null → 刷新评论列表"评论成功"
    end

    alt 删除评论(按 d,本人或管理员)
        M->>S: store.removeComment(cid, uid, role)
        S->>S: 递归删除子评论, comment_count 递减
        S->>F: save() 落盘
        S-->>M: "评论已删除"
    end
```

## 6. 删除头条流程（y/n 二次确认 + 级联删除）

```mermaid
flowchart TD
    A[我的头条或管理面板按 x] --> B[confirmAction=id 提示 确认删除? y/n]
    B -- n --> C[confirmAction=null 已取消]
    B -- y --> D[store.remove hid, uid, role]
    D --> E{头条存在?}
    E -- 否 --> ERR[头条不存在]
    E -- 是 --> F{本人发布 或 role=1?}
    F -- 否 --> ERR2[只能删除自己发布的头条]
    F -- 是 --> G[删除 headlines 记录]
    G --> H[级联删除该 hid 全部 likes]
    H --> I[级联删除该 hid 全部 comments]
    I --> J[save 落盘 refreshTick++ 刷新列表]
```
